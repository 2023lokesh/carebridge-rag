# 05 — Generated answers, citations and refusal evaluation

**Status as of October 10, 2026:** B0–B3 **code is merged and CI passes**, but **the actual generation workflow has not run** and no real human answer-quality scores exist yet. The public Render demo still uses a *small manually curated corpus*, not the 163-page Chroma experimental index.

**Controlled DEV protocol (merged [PR #14](https://github.com/2023lokesh/carebridge-rag/pull/14), approved by `ashakiran412`):** all four configurations use the same CPU-local **HuggingFaceTB/SmolLM2-360M-Instruct** generator, greedy decoding and 96-new-token cap. B0 receives no external passages; B1 gets BM25 fixed top five; B2 MiniLM cosine fixed top five; B3 heading-aware BM25+dense RRF of 20 candidates, real cross-encoder reranks top five. All 24 frozen DEV questions run under each condition: **96 real answers only when the workflow succeeds**. No 16 TEST items are loaded.

Workflow: `.github/workflows/evaluate-generation-dev.yml`, using existing GitHub Actions secret `CAREBRIDGE_DEV_GOLD_GZIP_B64`, and index build artifact from run `38059975329`. The secret is checked against the published SHA-256 freeze. Public artifact contains only automated aggregate statistics and **encrypted private answer review**. Local `scripts/review_generation_dev.py` decrypts on a trusted machine; `scripts/score_human_review.py` refuses incomplete reviewer identity/date/correctness/citation/refusal/safety fields.

**Automated marker validity is not passage support.** True factual correctness, claim-level citation entailment, correct refusal vs over-refusal, medical safety and hallucination require independent human review of all 96 outputs. The instructor's >=15 actual hand-labelled failures must be observed, not invented.

**Observed deterministic DEV rule-screen finding:** before the safety vocabulary fix, 7 of 24 prompts were blocked, including *two unwarranted* generic polio/varicella educational questions. A local regression fixed those; afterward 5 of 24 prompts were blocked (four unanswerable and one personal-medical ambiguous prompt). These are **rule-based screening diagnostics**, not measured LLM refusal performance. Injection resistance, temporal staleness and medical source support need live transcripts/human verification. Do not claim clinical safety certification or HIPAA compliance.
