# Course execution runbook

## Coursework completion workflows (October 2026 update)

The live demo is **not** a completed 150-page / neural-reranked graded project. The files below add truthful evidence workflows. **Never report an unexecuted crawl as completed.**

1. **Configure a descriptive contact address:** a repo admin sets GitHub Actions secret `CRAWL_CONTACT_EMAIL` to an address approved for public academic crawling. The crawler refuses to run if absent; never place it in source code.
2. **Collect and audit:** In GitHub **Actions -> Collect and audit public CDC corpus -> Run workflow**, choose `max_pages` (165 attempts to allow for extraction losses but does not guarantee success). The workflow honors CDC robots.txt, throttles at least one second per HTTP request, excludes external/login/directory pages, archives raw bytes with SHA-256 *before* parsing, and records timestamps. It uploads raw, normalized and inventory files to an Actions artifact **even when thresholds fail**. The job fails if **150 distinct normalized page URLs, five actual normalized PDFs and three distinct table pages** are not met. Run it again after refining seeds if needed. Verify the artifact; do not label seeds or queues as successes.
3. **Golden set:** `data/practice_question_ideas.jsonl` contains **40 AI-suggested practice questions, not gold**. By the instructor's rule, students must independently author source-grounded questions, document actual URLs and quotes <=25 words, verify each question/answer and label, and disclose that the chatbot existed before they authored the items. Do not falsely claim Friday-before-model authorship. An independent, verified `data/gold_human.jsonl` is needed before any scored evaluation. `carebridge.benchmark` rejects draft entries.
4. **Two chunk strategies and migrations:** install `requirements-full.txt` on a machine with sufficient RAM/storage. From the saved normalized archive (never re-crawl for re-chunking), run `python -m carebridge.index --corpus data/normalized.jsonl --strategy fixed` and later `--strategy heading`. The versioned Chroma build verifies full ID equality then atomically switches the active collection pointer and deletes the old collection; stats include word-count proxies and document metadata. Record actual model-token lengths separately for grading.
5. **Benchmark safeguards:** after real corpus and verified gold are available, `python -m carebridge.benchmark --gold data/gold_human.jsonl --baseline B1 --split dev --output reports/b1_dev.json`. To run B2, first index `fixed`; for B3, index `heading`. Use `--baseline B2` or `B3`. B0 needs a real, approved closed-book LLM protocol and API key; the script refuses to invent scores. It produces *retrieval-only* metrics and latency, not manual answer correctness, refusal/citation ratings, full end-to-end cost or cross-encoder lift. Those still need completed human review. Preserve the untouched 40% split until the instructor-approved single final test run; the script requires `--confirm-test-once` and creates a local lock. Do not call practice results B0–B3.
6. **Collaboration:** follow [branch protection and review checklist](docs/BRANCH_PROTECTION.md), assign [Issues](https://github.com/2023lokesh/carebridge-rag/issues), and document reviewer approvals and every member's contributions. Existing direct-to-main history cannot be rewritten into compliant reviewed PRs.

### Exploratory, non-graded smoke metrics

`scripts/practice_diagnostics.py` measures actual local BM25 / TF-IDF proxy / hybrid candidate-URL matches on **29 answerable AI-suggested practice prompts** against the **small bundled demo data**. `reports/practice_diagnostics.json` stores the real run. This is **not** an independent human gold set, not a 150-page retrieval evaluation, not neural B2/B3, and not answer correctness. It's a transparent development diagnostic only. The new safety gate refuses obvious out-of-scope requests instead of citing unrelated CDC snippets.
